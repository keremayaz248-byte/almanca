# Konu 50 (Präteritum) – bağımsız inceleme

## Düzeltilenler
- Q "Ich ___, wir hätten mehr Zeit." (wünschte): "wünsche" de dilbilgisel olarak olabildiği için belirsizdi -> "Als Kind ___ ich mir immer einen Hund." (tr: Çocukken hep bir köpek isterdim), exp yenilendi.
- Q "Ich ___ lernen, aber ich war so müde." (wollte): zaman ipucu yoktu -> başına "Gestern" eklendi.
- Q als/war exp: "wurde hocanın sayfasında kullanılmıyor" -> "wurde = oldu/-laştı, anlam uymaz".
- sein/haben tablo notu: kaynakta olmayan "Yani konuşmada da war/hatte kullanılıyor" cümlesi silindi.
- Modal kural maddesi: "heute / jetzt -> Präsens" -> "jetzt (şimdi)" (alıştırmada yalnız jetzt var).
- Düzensiz 2/2 slayt kaynağı: "Teil-2 s.51" -> "s.50-51" (essen, sprechen s.50'de).
- Als slaydı: "als ile hep Präteritum" -> "als-cümlesindeki fiil hep Präteritum" (hocanın bazı ana cümleleri Perfekt).
