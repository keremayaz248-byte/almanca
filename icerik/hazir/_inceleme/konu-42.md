# Konu 42 (Futur I) - bağımsız inceleme

## Düzeltilenler
- 5 zaman slaydı: Perfekt çevirisi "yardım edememişim" (söylentisel -miş, yanlış) -> "yardım edemedim".
- Çekim tablosu: "Mirjam wird ... verbringen" üç noktalı -> alıştırma metninden tam cümle; not: yazar sesi "kısalttım" -> pasif.
- Tahmin/Söz/Plan: başlık notu "ben koydum" -> "ders hazırlayıcının gruplaması"; "Du wirst dein Diplom..." söz/niyet değil, öngörü -> Tahmin slaydına taşındı. Söz slaydındaki "hoca zaman sözcüklerini hep başa koyuyor" dayanaksız iddiası çıkarıldı; aufhören notu A2 s.10'a bağlandı.
- Tahmin slaydı: "Er wird bald ein Arzt" mastarsız (werden = olmak); hocanın bunu Futur I örnekleri arasında verdiği not edildi.
- Modal şema notu: "können, müssen, dürfen ile kurulabilir" -> kaynakta üç modal; wollen örneği s.85'te ayrıca (eklendi).
- "mit der Zeit": "üç ünlem" yanlıştı (sayfada ünlem dizisi var) -> düzeltildi (slayt + Soru 9 exp); "genellikle Futur I ile gelir" dayanaksızdı -> "dört örnekten üçünde werden". wird schwächer / wird einfacher mastarsız (werden = olmak) uyarısı eklendi.
- Soru 11 (Es ___ kalt): seçenek "ist" de dilbilgisel doğruydu (belirsiz) -> wird / werden / werde.
- Soru 16 (Ich ___ Jonas nicht helfen können): "habe" da doğru Perfekt kurar (belirsiz) -> werde / werden / wirst.

## Çıkarılanlar
- Yok (Sie wird Lehrerin zaten derste yoktu; hocanın "öğretmen olmak istiyor" çevirisi A2 s.242'de gerçekten var ve yanlış, dogrulama'da duruyor).
